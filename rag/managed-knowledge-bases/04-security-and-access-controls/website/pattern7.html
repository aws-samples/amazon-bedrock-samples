Pattern 7

Lambda Interceptor

Add a Lambda function as a request/response interceptor on the Gateway. Runs before and after each tool invocation for custom logic like dynamic filter injection, audit logging, rate limiting, or result redaction.

Interceptor Configuration

gw = ac.create_gateway(
    name="interceptor-gw",
    roleArn=GW_ROLE_ARN,
    protocolType="MCP",
    authorizerType="AWS_IAM",
    interceptorConfigurations=[{
        "interceptor": {"lambda": {"arn": LAMBDA_ARN}},
        "interceptionPoints": ["REQUEST", "RESPONSE"],
        "inputConfiguration": {"passRequestHeaders": True}
    }]
)

Interceptor Event Format

{
  "interceptionPoint": "REQUEST" | "RESPONSE",
  "gatewayId": "gw-abc123",
  "targetId": "tgt-xyz789",
  "requestHeaders": { ... },
  "toolName": "Retrieve",
  "toolInput": { ... },   // REQUEST events
  "toolOutput": { ... }   // RESPONSE events
}

🎯 When to Use

When you need custom pre/post processing on every Gateway request. The passRequestHeaders: true setting forwards HTTP headers to Lambda — essential for reading JWT claims or custom headers for identity-based logic.
