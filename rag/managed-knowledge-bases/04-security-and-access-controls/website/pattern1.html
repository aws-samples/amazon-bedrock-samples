Pattern 1

Direct SDK Access

The simplest pattern — IAM-authenticated SDK calls to create a managed Knowledge Base, ingest S3 documents, and retrieve results. No Gateway layer.

Three Retrieval APIs

APIReturnsUse When
RetrieveRaw chunks with scoresYou want source chunks for a custom RAG pipeline
RetrieveAndGenerateGenerated answer + citationsYou want end-to-end RAG with managed generation
AgenticRetrieveStreamDeduplicated chunks (streaming)Complex/multi-part queries, multi-KB retrieval

What You Get

  • ✓ Basic RAG pipeline
  • ✓ IAM authentication
  • ✓ CloudTrail audit logging
  • ✓ Managed vector store
  • ✓ All 3 retrieval APIs

What You Don't Get

  • ✗ Per-user scoping
  • ✗ KB ID hidden from agents
  • ✗ Centralized access control
  • ✗ Fine-grained authorization

Retrieve API — Raw Chunks

# Returns raw source chunks with relevance scores
response = dp.retrieve(
    knowledgeBaseId=kb_id,
    retrievalQuery={"text": "What is Amazon Bedrock?"},
    retrievalConfiguration={
        "managedSearchConfiguration": {
            "numberOfResults": 5
        }
    }
)

RetrieveAndGenerate API — Managed RAG

# Returns generated answer with citations back to source documents
response = dp.retrieve_and_generate(
    input={"text": "What is Amazon Bedrock and what are its key features?"},
    retrieveAndGenerateConfiguration={
        "type": "KNOWLEDGE_BASE",
        "knowledgeBaseConfiguration": {
            "knowledgeBaseId": kb_id,
            "modelArn": GENERATION_MODEL,
            "retrievalConfiguration": {
                "managedSearchConfiguration": {"numberOfResults": 5}
            }
        }
    }
)

AgenticRetrieveStream API — Multi-KB Streaming

# Decomposes complex queries, runs multiple retrievals, streams deduplicated chunks
response = dp.agentic_retrieve_stream(
    messages=[{
        "role": "user",
        "content": {"text": "What are the main topics covered?"}
    }],
    retrievers=[{
        "configuration": {
            "knowledgeBase": {
                "knowledgeBaseId": kb_id,
                "retrievalOverrides": {"maxNumberOfResults": 10}
            }
        }
    }],
    agenticRetrieveConfiguration={
        "foundationModel": {"bedrock": {"modelArn": GENERATION_MODEL}},
        "maxAgentIteration": 3
    }
)

Key Differences

  • • Retrieve: managedSearchConfiguration — returns raw chunks, you build the prompt
  • • RetrieveAndGenerate: knowledgeBaseConfiguration with modelArn — returns generated text + citations
  • • AgenticRetrieveStream: messages + retrievers — streaming, multi-KB, query decomposition

Note: messages[0].content in AgenticRetrieveStream is a struct {"text": "..."}, not a list. The s3Location.uri in results is an HTTPS URL, not an s3:// URI.

🎯 When to Use

Internal tools, prototypes, single-tenant apps where IAM is sufficient. Great for getting started quickly with a managed RAG pipeline.
