Full Governance Stack

The complete security model combining all layers: Cognito JWT for authentication, Cedar for authorization, Lambda interceptor for custom processing, and metadata filters for document-level scoping.

Full Stack Gateway Creation

gw = ac.create_gateway(
    name="full-governance-gw",
    roleArn=GW_ROLE_ARN,
    protocolType="MCP",
    authorizerType="CUSTOM_JWT",
    authorizerConfiguration={"customJWTAuthorizer": {
        "discoveryUrl": discovery_url,
        "allowedAudience": [client_id],
        "allowedClients": [client_id]
    }},
    policyEngineConfiguration={
        "arn": pe_arn,
        "mode": "LOG_ONLY"
    },
    interceptorConfigurations=[{
        "interceptor": {"lambda": {"arn": LAMBDA_ARN}},
        "interceptionPoints": ["REQUEST", "RESPONSE"],
        "inputConfiguration": {"passRequestHeaders": True}
    }]
)

End-to-End Flow

  • 1. Client authenticates with Cognito → JWT
  • 2. Client calls Gateway with Bearer token
  • 3. Gateway validates JWT via OIDC
  • 4. Cedar evaluates authorization
  • 5. Lambda interceptor runs (REQUEST)
  • 6. KB Target executes with metadata filters
  • 7. Lambda interceptor runs (RESPONSE)
  • 8. Results returned through Gateway

Production Capabilities

  • ✓ Multi-tenant document isolation
  • ✓ Audit trails on every query
  • ✓ Per-role document visibility
  • ✓ Defense-in-depth security
  • ✓ PII redaction capability
  • ✓ Rate limiting support

🎯 When to Use

Multi-tenant SaaS with per-tenant document isolation. Regulated industries requiring audit trails on every query. Applications where different user roles see different document sets. Production deployments requiring defense-in-depth.
