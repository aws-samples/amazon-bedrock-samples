Managed Knowledge Bases
Security Patterns

8 progressive patterns for securing Amazon Bedrock Managed Knowledge Bases — from simple IAM access to full multi-tenant governance with JWT, Cedar, and Lambda interceptors.

01

Direct SDK Access

IAM-authenticated SDK calls to create, ingest, and retrieve. No Gateway layer.

IAM · Bedrock API
02

Access Control Filters

Document-level access control via metadata sidecar files — scope by department, role, tenant.

Access Control · Metadata · Sidecars
03

Gateway + IAM

AgentCore Gateway hides KB ID from agents. Standard MCP interface.

Gateway · MCP · IAM
04

Gateway + Cedar

Cedar Policy Engine for per-principal authorization. LOG_ONLY and ENFORCE modes.

Cedar · Policy-as-Code
05

JWT + Cognito

Token-based authentication via Cognito User Pools. Per-user identity.

JWT · Cognito · OIDC
06

JWT + Cedar

Two-layer auth: JWT validates WHO, Cedar decides WHAT. Multi-tenant ready.

Multi-Tenant · JWT · Cedar
07

Lambda Interceptor

Custom pre/post processing — dynamic filter injection, audit, redaction.

Lambda · Interceptor
08

Full Governance

All 5 layers combined: JWT + Cedar + Interceptor + Gateway + Metadata Filters.

Production · Defense-in-Depth
