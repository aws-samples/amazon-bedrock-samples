AgentCore Gateway + IAM

Add a Gateway layer between agents and the Knowledge Base. The Gateway hides the KB ID from agents and provides a standard MCP interface.

Create Gateway + KB Target

# Create Gateway with IAM auth
gw = ac.create_gateway(
    name="my-gateway",
    roleArn=GW_ROLE_ARN,
    protocolType="MCP",
    authorizerType="AWS_IAM"
)

# Create KB Target — connects Gateway to Knowledge Base
target = ac.create_gateway_target(
    gatewayIdentifier=gw_id,
    name="kb-retrieve",
    targetConfiguration={
        "mcp": {
            "connector": {
                "source": {"connectorId": "bedrock-knowledge-bases"},
                "configurations": [{
                    "name": "Retrieve",
                    "parameterValues": {
                        "knowledgeBaseId": kb_id
                    }
                }]
            }
        }
    }
)

🎯 When to Use

When you need to hide KB IDs from agents and provide a centralized MCP interface. The Gateway acts as a reverse proxy — agents connect to the Gateway URL, and the Gateway routes requests to the configured KB target.
